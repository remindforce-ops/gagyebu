# 가계부

휴대폰과 PC에서 쓰는 개인 가계부입니다. 기록은 **내 구글 드라이브의 '가계부' 구글시트**에 저장됩니다.

- 화면과 데이터 처리를 모두 구글시트에 붙은 **Apps Script 웹 앱**이 담당합니다.
- 웹 앱 접근 권한은 **나만(MYSELF)** 입니다. 구글이 내 계정 로그인 여부를 직접 확인하므로, 주소를 알아도 다른 사람은 열 수 없습니다.
- 이 저장소에는 개인정보, 키, 시트 주소, 웹 앱 주소가 들어 있지 않습니다. GitHub는 코드 보관용입니다.

## 사용하기

1. PC 브라우저에서 웹 앱 주소를 엽니다. (script.google.com → '가계부' 프로젝트 → **배포 → 배포 관리**에서 확인)
2. 휴대폰은 앱의 **⚙ 설정**에 있는 QR 코드를 카메라로 찍고, 열린 화면에서 **홈 화면에 추가**를 합니다.
   - 휴대폰 브라우저에 내 구글 계정이 로그인되어 있어야 합니다.
   - 구글 계정을 여러 개 로그인해 두었다면, 내 계정이 아닌 계정으로 열릴 때 오류가 날 수 있습니다. 이때는 다른 계정에서 로그아웃하거나 시크릿 창에서 내 계정으로만 로그인하세요.

## 영수증으로 입력하기

1. 화면 오른쪽 아래 **📷 버튼**을 누르고 영수증을 찍거나 사진을 고릅니다.
2. 구글 드라이브 OCR이 글자를 읽고, 앱이 **사용처·합계 금액·날짜·결제수단·카테고리**를 찾아 입력창에 채웁니다.
3. 내용을 확인·수정한 뒤 **[저장]** 을 누릅니다.

- 사진은 글자 인식용 임시 문서로만 쓰고 **바로 영구 삭제**합니다. 드라이브에 남지 않습니다.
- 영수증 형식에 따라 일부 값을 못 찾을 수 있으니 저장 전에 꼭 확인하세요.

## 직접 설치하려면

1. 구글시트를 하나 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `apps-script/` 폴더의 파일을 같은 이름으로 만들어 붙여넣습니다. (`appsscript.json`은 프로젝트 설정에서 '매니페스트 파일 표시'를 켜면 보입니다)
3. **배포 → 새 배포 → 웹 앱**을 고르고, 실행 사용자는 **나**, 액세스 권한은 **나만**으로 둡니다.

## 시트 구조

`내역` 탭에 아래 열이 저장됩니다. 시트에서 직접 고쳐도 앱에 반영됩니다. (ID 열은 지우지 마세요)

| ID | 날짜 | 구분 | 금액 | 카테고리 | 결제수단 | 사용처 | 메모 | 등록시각 |
|---|---|---|---|---|---|---|---|---|

## 파일 (`apps-script/`)

| 파일 | 역할 |
|---|---|
| `Code.js` | 화면 제공, 시트 읽기·쓰기, 영수증 OCR |
| `index.html` | 화면 구조 |
| `style.html` | 디자인 (라이트/다크 모드 자동) |
| `app.html` | 입력·목록·월별 합계, 영수증 내용 해석 |
| `appsscript.json` | 권한(이 시트, 앱이 만든 드라이브 파일만)과 웹 앱 접근 설정(나만) |
