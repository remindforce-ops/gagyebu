# 가계부

휴대폰과 PC에서 쓰는 개인 가계부입니다. 기록은 **내 구글 드라이브의 구글시트**에 저장됩니다.

- 이 저장소에는 개인정보, API 키, 시트 주소가 들어 있지 않습니다.
- Client ID와 시트 ID는 앱의 **설정** 화면에서 입력하며, 사용하는 기기의 브라우저에만 저장됩니다.
- 구글 로그인 토큰은 1시간 동안 유효합니다. 시간이 지나면 앱 상단의 **[구글 연결]**을 한 번 누르면 됩니다.

## 처음 설정 (한 번만, 약 10분)

### 1. Google Cloud에서 Client ID 만들기

1. <https://console.cloud.google.com> 에 접속해 **새 프로젝트**를 만듭니다. (이름 예: `gagyebu`)
2. **API 및 서비스 → 라이브러리**에서 `Google Sheets API`를 검색해 **사용**을 누릅니다.
3. **Google 인증 플랫폼(OAuth 동의 화면)** 으로 이동합니다.
   - 앱 이름: `가계부`, 사용자 지원 이메일: 내 계정
   - 대상(User type): **외부(External)**
   - **테스트 사용자**에 내 구글 계정을 추가합니다. (게시 상태는 '테스트'로 두면 됩니다)
4. **클라이언트 → 클라이언트 만들기**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 JavaScript 원본**: `https://<내 GitHub 아이디>.github.io`
   - 만들어진 **클라이언트 ID**(`…apps.googleusercontent.com`)를 복사합니다.
   - ⚠ 클라이언트 **보안 비밀(Client secret)** 은 이 앱에 필요 없습니다. 어디에도 붙여넣지 마세요.

### 2. 앱에 연결하기

1. 배포된 주소(`https://<내 GitHub 아이디>.github.io/gagyebu/`)를 엽니다.
2. 오른쪽 위 **⚙ 설정**을 엽니다.
3. **Client ID**를 붙여넣습니다.
4. 시트를 새로 만들려면 **[새 시트 만들기]**를 누릅니다. 이미 있는 시트를 쓰려면 시트 주소를 붙여넣고 **[저장하고 연결]**을 누릅니다.
5. 구글 로그인 창에서 "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → 가계부(으)로 이동**을 누릅니다. 내가 만든 앱이므로 안전합니다.

> 휴대폰과 PC는 각각 한 번씩 설정해야 합니다. (설정값은 기기마다 따로 저장됩니다)

### 3. 휴대폰 홈 화면에 추가

- **iPhone (Safari)**: 공유 버튼 → **홈 화면에 추가**
- **Android (Chrome)**: ⋮ 메뉴 → **홈 화면에 추가** 또는 **앱 설치**
