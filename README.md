# 가계부

휴대폰과 PC에서 쓰는 개인 가계부입니다. 기록은 **내 구글 드라이브의 '가계부' 구글시트**에 저장됩니다.

- 구글시트에 붙은 **Apps Script 웹 앱**이 읽기·쓰기를 대신 처리하므로, 앱에서 따로 로그인할 필요가 없습니다.
- 이 저장소에는 개인정보, 키, 시트 주소, 웹 앱 주소가 들어 있지 않습니다.
- 웹 앱 주소는 연결 페이지를 통해 각 기기 브라우저에만 저장됩니다. **웹 앱 주소(연결 페이지, QR 코드)를 아는 사람은 가계부를 읽고 쓸 수 있으니 공유하지 마세요.**

## 기기 연결

1. Apps Script 웹 앱 주소(연결 페이지)를 PC 브라우저에서 엽니다.
   - 처음 한 번은 구글이 권한을 묻습니다. "확인되지 않은 앱" 경고가 나오면 **고급 → 이동 → 허용**을 누릅니다. 내가 만든 스크립트이고, 이 시트 하나에만 접근합니다.
2. **PC**: [이 기기에서 가계부 열기] 버튼을 누릅니다.
3. **휴대폰**: 연결 페이지의 QR 코드를 카메라로 찍은 뒤, 열린 화면에서 **홈 화면에 추가**를 합니다.
   - iPhone (Safari): 공유 버튼 → 홈 화면에 추가
   - Android (Chrome): ⋮ 메뉴 → 홈 화면에 추가

## 처음부터 직접 설치하려면

1. 구글시트를 하나 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `apps-script/` 폴더의 `Code.js`, `setup.html`, `appsscript.json` 내용을 붙여넣습니다. (`Code.js`의 `APP_URL`을 내 GitHub Pages 주소로 바꿉니다)
3. **배포 → 새 배포 → 웹 앱**을 고르고, 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 둡니다.
4. 나온 웹 앱 주소로 위의 '기기 연결'을 진행합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 디자인 (라이트/다크 모드 자동) |
| `app.js` | 입력·목록·월별 합계 |
| `api.js` | Apps Script 웹 앱과 통신 |
| `apps-script/` | 구글시트에 붙는 Apps Script 코드와 연결 페이지 |
